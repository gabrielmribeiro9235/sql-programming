# SQL Programming

Repositório com exercícios, exemplos e experimentos desenvolvidos ao longo do meu aprendizado de **SQL e Bancos de Dados**.

Os conteúdos abordam criação e manipulação de estruturas de banco de dados, restrições, relacionamentos, consultas e outros recursos do SQL, explorados por meio de exercícios práticos e pequenos exemplos.

## Conteúdos

* DDL e criação de tabelas
* Alteração e remoção de estruturas
* Chaves primárias e estrangeiras
* Restrições (`UNIQUE`, `CHECK`, `NOT NULL` e `DEFAULT`)
* DML e manipulação de dados
* Consultas SQL
* Relacionamentos e `JOINs`
* Exercícios de Banco de Dados

Os códigos estão organizados por tema e fonte de estudo, reunindo exercícios de diferentes materiais e atividades acadêmicas.
